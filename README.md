# black-friday-sales-analysis
Black Friday Sales Analysis - Maven Ski Shop (Data Prep + Analysis using Python)

## 📌 Project Overview
This project analyzes Black Friday sales data for a retail ski shop.

The dataset required preprocessing, including handling missing values and calculating key metrics such as sales tax and total transaction amounts.

---

## 🎯 Key Objectives

1. Read data from an Excel workbook  
2. Process and clean raw data  
3. Compute missing tax and total values  
4. Automate Excel operations using Python  
5. Prepare dataset for further analysis

*Dataset provided as part of a Maven Analytics case study.*
