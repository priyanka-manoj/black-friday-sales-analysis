# black-friday-sales-analysis
Black Friday Sales Analysis - Maven Ski Shop (Data Prep + Analysis using Python)

## 📌 Project Overview
This project analyzes Black Friday sales data for a retail ski shop.

The dataset required preprocessing, including handling missing values and calculating key metrics such as sales tax and total transaction amounts.

---

## 🎯 Key Objectives

1. Read data from an Excel workbook  
2. Process and clean raw data  
3. Compute missing tax and total values  
4. Automate Excel operations using Python  
5. Prepare dataset for further analysis

*Dataset provided as part of a Maven Analytics case study.*

---

## 📊 Part 2: Data Analysis

### 📌 Objective
After preparing the dataset, the next step is to analyze Black Friday sales performance by calculating key metrics and identifying patterns in the data.

---

## 🎯 Key Objectives

1. Define a function to aggregate (sum) Excel columns  
2. Calculate key performance indicators (KPIs)  
3. Identify unique values using set operations  
4. Create grouped summaries using dictionaries  
5. Analyze sales by category and other dimensions  

---

## 📈 Analysis Focus

The analysis aims to answer questions such as:
- What is the total revenue generated?
- Which products or categories performed best?
- How do different segments contribute to sales?
- What trends can be observed in customer purchases?
